# Universal Agent UI Pilot

Интерактивный UI-пилот универсального AI-чата НОРМ. Он показывает нового агента внутри существующего продуктового интерфейса: историю диалогов, компактный статус работы, раскрываемый технический trace, источники, субагентов, ошибки, файлы, таблицы и графики.

Данные и ответы в этой версии демонстрационные. Подключение к production API не требуется.

## Локальный запуск

Нужны Node.js 18 или новее и npm.

```bash
cd pilot
npm ci
npm run dev
```

Откройте <http://127.0.0.1:4410/>.

## Проверка сборки

```bash
cd pilot
npm run typecheck
npm test
npm run build
```

## Доступные сценарии

- обычная проверка;
- модель без рассуждений;
- два источника сразу;
- работа с экспертом;
- источник без данных;
- источник недоступен;
- файл, таблица и график;
- регистрация события;
- обычный чат без формы.

Исходные компоненты продукта находятся в `src`, а автономная демонстрационная оболочка и mock-сценарии — в `pilot`.

## Как рисуется ход работы

Правила для фронтенда. Код: `src/components/AgentActivity/model.ts` (что считается шагом, статусы, время) и `AgentTrace.tsx` (отрисовка).

**Шаги.** Шаг — это вызов источника (`toolCall`) или эксперта (`delegation`) **уровня оркестратора**. Результат вызова отдельным шагом не показывается: достаточно того, что источник вызывали. Отказ (`error`) и пустая выдача (`empty`) складываются в строку своего вызова: «Реестр рисков — недоступен» и текст отказа под ней.

**Названия.** Источник или эксперт называется по роли, а не по имени тула: словарь `toolNames` (`ask_methodologist` → «Методолог», `get_company_risks` → «Реестр рисков» и т. д.). Новый тул — новая строка в словаре.

**Эксперт — один шаг.** Всё, что происходит внутри субагента (события с `parentCallId`): его вызовы, рассуждение, реплики, возврат (`handback`), — не показывается. Длительность эксперта считается от `delegation` до его `handback`.

**Рассуждение не отдельный шаг, а принадлежит следующему вызову.** Всё рассуждение оркестратора (`thinking` без `parentCallId`), пришедшее после предыдущего шага и до начала вызова, привязывается к этому вызову: у строки появляется стрелка, по нажатию рассуждение раскрывается. По умолчанию свёрнуто.
- Рассуждение приходит потоком, кусками: подряд идущие куски склеиваются в один текст.
- Пока следующего вызова ещё нет, рассуждение копится в живой строке «Думаю» в конце хода работы — тоже свёрнутой, со стрелкой; как только начался вызов, строка «Думаю» сменяется строкой источника с тем же рассуждением под стрелкой. Обе строки одной высоты, экран не прыгает.
- Свёрнуто или раскрыто — это состояние самого рассуждения, а не строки: если человек раскрыл «Думаю», у источника рассуждение останется раскрытым.
- Нет рассуждения (модель его не отдаёт или оно не пришло) — нет и стрелки, строка просто называет источник.
- Модель вызвала несколько источников одним ходом — рассуждение у первого из них.
- Рассуждение после последнего вызова (перед самим ответом) привязать не к чему: оно остаётся последней строкой хода работы, свёрнутой. Пока идёт прогон, строка называется «Думаю», после ответа — «Итоговое рассуждение».
- Рассуждение внутри субагента не показывается никогда.

**Реплики.** Промежуточный текст модели (`message` без `label`) не показывается. Служебные шаги бэкенда (`message` с `label`, например «Спросил методолога») показываются как есть.

**Время.**
- У каждого шага — сколько отвечал источник или эксперт, целыми секундами, как секундомер: «0 с», «1 с», … (без «<1 с»). Пока вызов открыт, число растёт раз в секунду; после результата остаётся итоговое; обрыв прогона останавливает счёт.
- В шапке хода работы — общее время ответа: «Ответ готов за 18 с».
- В плашке времени нет.

**Плашка (свёрнутый статус).** Пока идёт прогон, статусов три — плашка не называет каждый тул, какой именно источник работает, видно в ходе работы:
- «Думаю» — ни один вызов не открыт: до первого вызова, между вызовами и перед ответом. Есть у модели рассуждение или нет — не важно;
- «Собираю источники» — открыт вызов источника (Законы, Реестр рисков, Зарегистрировать меру); несколько сразу — тот же статус;
- «Делегирую: методолог» — работает эксперт-субагент (Профайлер, Методолог, Аналитик). Эксперт работает дольше источника, поэтому, если вместе с ним открыт источник, плашка называет эксперта. Внутренние вызовы эксперта плашку не меняют.

Ответ одного из параллельных вызовов статус не сбрасывает, пока открыт другой. В конце — «Ответ готов» или «Не удалось завершить ответ».

**Чего пока нет в контракте с чатом НОРМа.** Обратный вызов `/ainvoke` сейчас присылает шаги одной пачкой после конца прогона и без рассуждения и времени. Для этой картинки бэкенду нужно отдавать рассуждение оркестратора, начало и конец каждого вызова, а для живых счётчиков и плашки — делать это по ходу прогона.
